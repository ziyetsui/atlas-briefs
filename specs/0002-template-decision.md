## Atlas brief 模板 · 原型定稿（2026-10-15）

在 `proto/` 里做了 5 页 × 4 个方向，用 picker 挑选。下面是定下来的模板，正式版在 `final/`。

### 页面结构

| # | 页面 | 文件 | 选定方向 |
|---|---|---|---|
| 0 | 我的产品（封面） | `final/index.html` | 简洁封面：产品信息 + 本轮目标 + 4 步入口。总览页的 4 个方向都没选，改成这个封面 |
| 1 | 锁定竞品 | `final/competitors.html` | **四象限**：相关性 (x) × 爆品度 (y) 散点图，气泡面积 = 素材量；60/60 分界，右上「核心对标」；入选的 3 个直接标名字，右侧写结论和 3 张竞品卡 |
| 2 | 竞品爆款 | `final/hits.html` | **象限**（按数据列）：点赞（对数）× 可迁移度，颜色区分形式，实心 = 爆款；点图例或点 → 侧栏出该形式的 3 个例子 |
| 3 | 爆款拆解 | `final/teardown.html` | **看板**：bento 网格：账号 / 流量 / 漏斗 / 结构 / 为什么 / 放到我的产品上 |
| 4 | 规律与落地 | `final/playbook.html` | **映射**：按规律切换，左边「竞品怎么做」（3 例），右边「我怎么做」（示意封面 + 脚本 + KPI） |

### 流量从哪来：定量 + 定性（第 3 页，2026-10-15 新增）

- **定量**（`traffic.quant`，可为 null）：搜索 / 发现页 / 聚光信息流 / 其他的占比，10 天累计曲线，峰值与追投；必须标注数据来源（`from`）。
- **定性**（`traffic.qual`，必填）：判断流量类型（推荐流型 / 搜索长尾型 / 投放驱动型）并写一句理由；关键词表写清每个词出现在 标题 / 封面 / 正文 / 话题 的哪里、起什么作用；最后列出推测的长尾搜索词。
- 竞品笔记通常拿不到后台数据，这时 `quant: null`，页面只展示定性判断，不画空图表。

### 没选的方向

| 页面 | 没选 | 当时记录的代价 |
|---|---|---|
| 总览 | 长卷 / 脉络 / 画廊 / 目录 | 都没选，用封面页代替 |
| 锁定竞品 | 九宫格 | 分档会丢精度（92 和 76 落在同一格） |
| 锁定竞品 | 筛选（14→10→5→3） | 要点几步才能看到结论 |
| 锁定竞品 | 评分卡 | 最像表格，不像 brief |
| 竞品爆款 | 货架（按内容列） | 竞品之间不能并排比较 |
| 竞品爆款 | 对照（竞品 × 形式交叉格） | 密，封面太小 |
| 竞品爆款 | 瀑布流 | 「形式」这一层被压成筛选条件，结构最弱 |
| 爆款拆解 | 档案 / 链路 / 批注 | 档案太长；链路把结构挤到下面；批注要等真实抽帧 |
| 规律与落地 | 规律卡 / 矩阵 / 行动表 | 规律卡最长；矩阵的缩略图看不清；行动表的 4 周计划是写死的 |

### 数据契约

`final/assets/data.js` 的结构就是爬虫和 research 的输出格式：`product`、`pool`（候选品牌 + 子分数）、`competitors[].formats[].notes`、`teardowns[formatId]`（account / traffic{quant,qual} / money / structure / why）、`laws[]`、`scatter`。虚构的示例数据留在 `proto/shared/data.js`。

### 第一份真实 brief：拍吧（2026-10-15）

- 数据：线上素材库 `atlas-final…/atlas/ad-creative/library/` 的 13,749 条小红书笔记，导出在 `data/library/`（items.json + det.json）。重新生成数据：`python3 scripts/build_pepa.py data/library final/assets/data.js`。
- 素材库里没有和拍吧同类的「素人视频任务平台」，所以竞品按「抢同一批人（想用手机赚零花钱）、讲同一个故事（拍/发内容就能赚钱）」来圈：圈出 8 组候选，留下 超自然行动组（百万激励计划）、京东 · 夺金密令、副业接单赛道。
- 数据边界：只有榜单百分位、排名和投放目标（应用下载 / 蒲公英合作 / 客资收集），**没有点赞数和粉丝数**；发布日期由笔记 ID 推算。相关性和可迁移度是判断分，爆品度是用榜单数据算出来的。
- 页面改动：爆款象限横轴改为「榜内百分位」；拆解页定量 = 榜单记录（不再是流量来源占比和曲线），变现 = 步骤链（没有数字）。
